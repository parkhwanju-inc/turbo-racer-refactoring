# 코드에서 이상한 곳 (code smells)

지금 코드만 읽고 정리했어요 (git 기록은 안 봄). 위쪽일수록 실제 버그에 가까운 항목이에요.

> 줄번호는 **리팩토링 전** 코드 기준이에요 (`public/game.js`, 한 파일짜리 `server.py`). 구조 문제(복사된 코드, 전역 변수, IE 코드 등)는 `refactor/cleanup`에서 정리했고, 동작이 바뀌는 버그는 일부러 그대로 두었어요.
